# Parchís Online

Parchís pirata online para cuatro jugadores con conexión robusta, peleas de captura y tablero en relieve.

Made with [CodeAgent Remix](https://www.codeagent-mobile.com/remix). Live app: https://parchis-online-cbhjh4ql.remixapps.app/

## Run it locally

A React Native app for [Expo](https://expo.dev) (SDK 54), in TypeScript. You need Node.js 20 or newer.

```bash
npm install
npx expo start   # scan the QR code with Expo Go
```
